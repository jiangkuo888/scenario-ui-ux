# scenario-ui-ux

场景导向的产品界面设计与自检技能。以用户完成任务为单位组织页面，沿真实操作路径验收。

## 适用场景

- 页面拥挤，浏览、创建、编辑、审核等任务混在一起。
- 当前对象、保存状态或下一步不清楚。
- 界面改版后，需要检查真实操作流程、状态恢复及截图证据。

技能包含六项设计原则、五步工作流程和操作自检清单。正文为中文，发现描述为英文。

## 安装

### Codex

将仓库克隆到个人技能目录。目标目录已存在时，先检查现有内容，避免覆盖。

```bash
git clone https://github.com/jiangkuo888/scenario-ui-ux.git ~/.agents/skills/scenario-ui-ux
```

### Claude Code

```bash
git clone https://github.com/jiangkuo888/scenario-ui-ux.git ~/.claude/skills/scenario-ui-ux
```

其他支持 `SKILL.md` 的工具，可将仓库目录放入对应的技能发现路径。

## 使用

在支持技能调用的助手中明确指定：

```text
使用 $scenario-ui-ux 检查订单审核流程，按用户任务整理页面，并沿实际入口验证保存、返回、刷新和失败重试。
```

实施前读取目标项目的规则、组件和视觉令牌。项目已有界面契约时，使用该项目自己的规范与检查工具；本技能不附带特定项目的组件库、数值令牌或浏览器环境。
